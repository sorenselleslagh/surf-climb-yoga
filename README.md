# Surf & Climb Yoga

15-minute yoga flexibility sessions for surfing and climbing, with sound-cued timer, pose illustrations, sunrise/sunset times and on-device session history.

Live app: https://sorenselleslagh.github.io/surf-climb-yoga/

## Add to your home screen

**iPhone:** Open the link in Safari, tap Share, then **Add to Home Screen**.

**Android:** Open the link in Chrome, tap the menu, then **Add to Home screen** or **Install app**.
